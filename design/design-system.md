# Doce Encanto design system

## Visual concept

An artisan confectionery counter translated into a calm editorial storefront. The memorable move is the scalloped transition between the product-led hero and the catalog; all other surfaces stay restrained.

## Tokens

- Ivory background: `#FFF9F5`
- Clean white surface: `#FFFFFF`
- Berry rose: `#B74751`
- Deep cocoa: `#341713`
- Muted cocoa: `#725E59`
- Soft rose border: `#E9D3CF`
- Display type: Georgia with a high-contrast serif fallback
- Interface type: Segoe UI with system sans-serif fallbacks
- Radii: 6px controls, 18px images, no universal card shell
- Layout: 1200px maximum width, asymmetrical 5/7 hero, open catalog rail
